SEBLAK BOHAY — WEBSITE REVISI

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder Seblak_Bohay_Revisi.
3. Klik dua kali index.html atau buka melalui Google Chrome / Microsoft Edge.
4. Internet tidak diperlukan untuk menampilkan gambar karena gambar menu disertakan di folder images.

MENU DAN HARGA
- Aqua Gelas: Rp1.000
- Es Teh: Rp5.000
- Seblak Tulang: Rp15.000
- Seblak Seafood: Rp20.000
- Seblak Enoki: Rp15.000
- Seblak Komplit: Rp25.000
- Seblak Ceker: Rp20.000

FITUR
- Katalog menu dengan foto lokal.
- Detail produk: level pedas, topping, jumlah, dan catatan.
- Keranjang dengan subtotal, biaya kemasan, biaya layanan 2%, dan total.
- Checkout dengan validasi nama, nomor telepon, dan alamat.
- Nomor pesanan dan pelacakan status.
- Dashboard pengguna: riwayat transaksi, ringkasan belanja, menu favorit.
- Data tersimpan pada localStorage browser.

CATATAN
Ini adalah demo front-end untuk studi kasus. Data disimpan di browser/perangkat yang sama dan belum menggunakan database server terpusat atau login akun. Pembayaran transfer hanya simulasi, bukan gateway pembayaran sungguhan.
